# Conversor de Moedas 

Desafio do programa **Oracle Next Education (ONE)**.
O objetivo é criar um conversor de moedas que consome uma API para trazer dados reais.

## Funcionalidades
- Menu interativo no console.
- Conversão entre Dólar, Real, Peso Argentino e Colombiano.
- Conexão com a API externa para cotação atual.

## Tecnologias
- **Java 17**
- **Maven**
- **Gson** (para ler o JSON)
- **HttpClient**

## Como rodar
1. Clone o projeto.
2. Abra no seu IDE (IntelliJ).
3. Execute o arquivo `Principal.java`.
